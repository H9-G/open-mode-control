# Open Mode Control

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

既存のノートは閲覧モード、新規ノートは編集モードで開きます。それぞれのモードを選べ、特定のファイル・フォルダ・パターンには例外も設定できます。

## 機能

- **既存ノート**は、標準で閲覧モードで開きます。
- **新規ノート**は、標準で編集モード（ライブプレビュー）で開きます。
- どちらも、閲覧モード／ライブプレビュー／ソースモード／「変更しない」（Obsidian標準の動作）から変更できます。
- **例外設定**は、ファイル、フォルダ（サブフォルダ含む）、`Daily/**/*.md` のようなグロブで指定できます。上から順に判定し、最初に一致したルールを使います。例外は上の2つの設定より優先されます。
- コマンド「開いているノートを例外に追加」と、設定画面の同名のボタンがあります。
- 設定画面とコマンドは、英語・日本語・簡体字中国語・繁体字中国語・韓国語・スペイン語・フランス語・ドイツ語に対応しています。初回はObsidianの言語を自動で選び、設定から変更できます。

## 「新規」の判定

現在のセッション中に作成され、「新規ファイル判定の秒数」（標準10秒）以内に開いたノートを新規とみなします。空（0バイト）のノートも新規扱いです（設定でオフにできます）。同期で届いて後から開いたノートは既存扱いです。

## 動作の注意

- モードを切り替えるのは、ノートをタブで開いた瞬間だけです。タブの切り替えや、自分で行ったモード切替は上書きしません。
- Obsidian起動時に復元されるタブは、保存されたモードのままです。
- 対象はMarkdownノートのみです。
- ネットワーク通信やデータ収集は行いません。

## インストール

**コミュニティプラグインから：** 設定 → コミュニティプラグイン → 閲覧 で「Open Mode Control」を検索し、インストールして有効化します。

**手動：** 最新リリースの `main.js` と `manifest.json` を `<vault>/.obsidian/plugins/open-mode-control/` に置き、Obsidianを再読み込みして有効化します。
