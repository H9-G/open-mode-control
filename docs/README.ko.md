# Open Mode Control

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

기존 노트는 읽기 보기로, 새 노트는 편집 보기로 엽니다. 각각의 모드를 선택할 수 있으며 특정 파일, 폴더 또는 패턴에 예외를 설정할 수 있습니다.

## 기능

- **기존 노트**는 기본적으로 읽기 보기로 열립니다.
- **새 노트**는 기본적으로 편집 보기(라이브 프리뷰)로 열립니다.
- 둘 다 읽기 보기, 라이브 프리뷰, 소스 모드, 또는 '변경하지 않음'(Obsidian 기본 동작)으로 바꿀 수 있습니다.
- **예외**는 파일, 폴더(하위 폴더 포함) 또는 `Daily/**/*.md` 같은 글롭 패턴으로 지정합니다. 규칙은 위에서부터 차례로 확인하며 처음 일치하는 규칙을 사용하고, 위의 두 기본 설정보다 우선합니다.
- '현재 노트를 예외에 추가' 명령과 설정 화면의 같은 버튼이 있습니다.
- 설정과 명령은 영어, 일본어, 중국어 간체, 중국어 번체, 한국어, 스페인어, 프랑스어, 독일어를 지원합니다. 처음에는 Obsidian의 언어를 따라 자동 선택되며 설정에서 바꿀 수 있습니다.

## '새 노트' 판정 방식

현재 세션에서 만들어졌고 '새 노트 판정 시간'(기본 10초) 안에 연 노트를 새 노트로 간주합니다. 빈(0바이트) 노트도 새 노트로 취급합니다(끌 수 있음). 동기화로 도착해 나중에 연 노트는 기존 노트로 취급합니다.

## 참고 사항

- 모드는 노트를 탭에서 여는 순간에만 적용됩니다. 탭 전환이나 직접 바꾼 모드는 덮어쓰지 않습니다.
- Obsidian을 시작할 때 복원되는 탭은 저장된 모드를 유지합니다.
- Markdown 노트만 대상입니다.
- 네트워크 요청을 보내지 않으며 데이터를 수집하지 않습니다.

## 설치

**커뮤니티 플러그인에서:** 설정 → 커뮤니티 플러그인 → 둘러보기에서 'Open Mode Control'을 검색해 설치하고 활성화합니다.

**수동 설치:** 최신 릴리스의 `main.js`와 `manifest.json`을 `<vault>/.obsidian/plugins/open-mode-control/`에 넣고 Obsidian을 다시 불러온 뒤 플러그인을 활성화합니다.
