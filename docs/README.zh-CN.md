# Open Mode Control

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

已有笔记以阅读视图打开，新笔记以编辑视图打开。可分别选择模式，并为特定文件、文件夹或模式设置例外。

## 功能

- **已有笔记**默认以阅读视图打开。
- **新笔记**默认以编辑视图（实时预览）打开。
- 两者都可改为阅读视图、实时预览、源码模式，或“不更改”（保持 Obsidian 默认行为）。
- **例外**可按文件、文件夹（含子文件夹）或通配符（如 `Daily/**/*.md`）设置。规则从上到下依次判断，使用第一个匹配的规则，并优先于上面两项默认设置。
- 提供命令“将当前笔记添加到例外”，设置中也有对应按钮。
- 设置和命令支持英语、日语、简体中文、繁体中文、韩语、西班牙语、法语和德语。首次使用时会根据 Obsidian 的语言自动选择，也可在设置中更改。

## “新笔记”的判定

在当前会话中创建、并在“新笔记判定时间”（默认 10 秒）内打开的笔记视为新笔记。空（0 字节）笔记也视为新笔记（可关闭）。通过同步到达、之后才打开的笔记视为已有笔记。

## 注意事项

- 仅在笔记于标签页中打开的那一刻应用模式。切换标签页或手动切换模式不会被覆盖。
- Obsidian 启动时恢复的标签页保持其已保存的模式。
- 仅影响 Markdown 笔记。
- 不发起网络请求，也不收集数据。

## 安装

**通过社区插件：** 打开 设置 → 社区插件 → 浏览，搜索“Open Mode Control”，安装并启用。

**手动安装：** 将最新发布版本中的 `main.js` 和 `manifest.json` 放入 `<vault>/.obsidian/plugins/open-mode-control/`，然后重新加载 Obsidian 并启用插件。
