# Open Mode Control

[English](../README.md) | [日本語](README.ja.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md)

既有筆記以閱讀檢視開啟，新筆記以編輯檢視開啟。可分別選擇模式，並為特定檔案、資料夾或模式設定例外。

## 功能

- **既有筆記**預設以閱讀檢視開啟。
- **新筆記**預設以編輯檢視（即時預覽）開啟。
- 兩者都可改為閱讀檢視、即時預覽、原始碼模式，或「不變更」（維持 Obsidian 預設行為）。
- **例外**可依檔案、資料夾（含子資料夾）或萬用字元（如 `Daily/**/*.md`）設定。規則由上到下依序判斷，採用第一個符合的規則，並優先於上面兩項預設設定。
- 提供指令「將目前的筆記加入例外」，設定中也有對應按鈕。
- 設定與指令支援英文、日文、簡體中文、繁體中文、韓文、西班牙文、法文與德文。首次使用時會依 Obsidian 的語言自動選擇，也可在設定中變更。

## 「新筆記」的判定

在目前工作階段中建立、並在「新筆記判定時間」（預設 10 秒）內開啟的筆記視為新筆記。空白（0 位元組）筆記也視為新筆記（可關閉）。透過同步抵達、之後才開啟的筆記視為既有筆記。

## 注意事項

- 僅在筆記於分頁中開啟的當下套用模式。切換分頁或手動切換模式不會被覆蓋。
- Obsidian 啟動時還原的分頁會保留其已儲存的模式。
- 僅影響 Markdown 筆記。
- 不發出網路請求，也不收集資料。

## 安裝

**透過社群外掛：** 開啟 設定 → 社群外掛 → 瀏覽，搜尋「Open Mode Control」，安裝並啟用。

**手動安裝：** 將最新發行版本中的 `main.js` 與 `manifest.json` 放入 `<vault>/.obsidian/plugins/open-mode-control/`，然後重新載入 Obsidian 並啟用外掛。
